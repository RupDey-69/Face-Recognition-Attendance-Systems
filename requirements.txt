## Required Packages

Install the required packages using the following command:

pip install Flask
pip install opencv-python
pip install face-recognition
pip install face-recognition-models
pip install numpy
pip install Pillow
pip install mysql-connector-python
pip install pyttsx3
pip install Werkzeug
pip install Jinja2
pip install click
pip install itsdangerous
pip install MarkupSafe
pip install blinker

## Recommended requirements.txt

Flask==3.1.1
opencv-python==4.12.0.88
face-recognition==1.3.0

pyttsx3==2.99

imutils==0.5.4
gunicorn==23.0.0


Install using:

pip install -r requirements.txt

---

## If You Face Installation Errors

Some systems may require the following packages before installing face_recognition:

pip install cmake
pip install dlib
pip install face-recognition

---

## Run the Project

python app.py
