## Required Packages <br>

Install the required packages using the following command: <br>

pip install Flask <br>
pip install opencv-python <br>
pip install face-recognition <br>
pip install face-recognition-models <br>
pip install numpy <br>
pip install Pillow <br>
pip install mysql-connector-python <br>
pip install pyttsx3<br>
pip install Werkzeug <br>
pip install Jinja2 <br>
pip install click <br>
pip install itsdangerous  <br>
pip install MarkupSafe <br>
pip install blinker <br>

pip install -r requirements.txt <br>

## If You Face Installation Errors  <br>

Some systems may require the following packages before installing face_recognition: <br>

pip install cmake <br>
pip install dlib <br>
pip install face-recognition <br>
